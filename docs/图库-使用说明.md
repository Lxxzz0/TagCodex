# 图库 · 使用说明

顶栏左边「词典 / 图库」切换，记住上次停在哪一页。撤销、导出、主题、反推和扫描的进度两页共用。

## 图片怎么放

图库根（`config.json` 的 `gallery_root`，扫描时也可以临时填别的）下面**随便怎么分文件夹都行**，任意一层的图都会登记，左栏按文件夹显示。比如：

```
图库根/
  *.png                       ← 直接放在根下也行，左栏「（根目录）」
  参考图/
    角色A/泳装/*.png
    角色A/泳装/细节/*.png     ← 多深都行
    新图/*.jpg
  生成/
    2026-10/*.webp
```

- 支持 png / jpg / jpeg / webp
- 有没有反推看提示词，不用按目录分：新图放进哪个文件夹都行，扫描后用左栏「状态 → 未反推」找出来反推，可以和文件夹筛选一起用
- 套图名 = 图片所在的文件夹名。从 txt / xlsx 导入的记录按「所在文件夹名 + 文件名」认图，所以 txt 目录名和图片所在的文件夹名一致时才能自动对上
- 不同父文件夹下的同名文件夹互不相干，左栏分开显示

## 日常流程

1. **放新图**：放进图库根下的任意文件夹，然后「添加 / 导入」→「扫描图库」→「开始扫描」。后台跑、可停止。没动过的图第二次扫只看大小和修改时间，很快
2. **反推**：左栏点「状态 → 未反推」（可以先点某个文件夹）→「全选本页」→「反推选中的图」，或点提示行里的「反推『…』下的全部图」（勾「跳过已反推的」就只反推还没提示词的）。参数沿用顶栏「反推设置」→「反推目录」里的设置。图片文件不会被移动
3. **整理文件夹**：在资源管理器里把图挪到别的文件夹后再扫描一次。扫描按文件内容认出是移动，标签、手工修改和关联都保留，左栏跟着变
4. **看提示词**：列表模式每行一张图，右边按段显示词，段的顺序就是拼接顺序。所有段都占一行（空段只有一个 `＋`），各张图的同一段上下对齐。默认紧凑：每段一行，放不下的折成 `+N`，点开看全部、再点「收起」。反推来的词按置信度分三档：≥ 0.80 亮、0.50–0.79 灰、< 0.50 暗灰虚线框；悬停看精确值，勾「显示置信度数字」直接显示
5. **改**：
   - 点一个词：归到别的段 / 拉黑（这两个改的是词典，含这个词的图一起变）/ 只从这张图删掉 / 在词典里查看
   - 段末尾的 `＋`（段已展开、或词都显示得下、或空段时才有）：给这张图加词。弹出挑词框，默认是点的那一段，上面可以换段；候选是词典里这一段的词（按出现次数，数字是出现在几张图），可以搜英文、中文、别名，点选多个，图上已经有的灰掉。词典里没有的词在搜索框里直接打（逗号分隔）回车加进已选；搜索框空着回车、或点「加上 N 个词」确定，Esc 或点外面取消。词按词典（新词按 danbooru > 规则表 > 未归类）落段，不一定落在你点的那段，会提示
   - 同一段里拖动词：只调这张图的词序。紧凑模式下这段有 `+N` 时先展开再拖
   - 全部可以撤销（Ctrl+Z 或顶部「撤销」）
6. **复制提示词**：每行的「复制提示词」或详情里的按钮。拼法：按段顺序，跳过不参与拼接的段和黑名单词，`, ` 连接。只要某一段（比如服饰）：打开详情，**点段名**就复制这一段的词（不带黑名单词，不参与拼接的段也能复制）
7. **找刚处理的那一批**：导入 / 反推 / 扫描报告里点「去图库看这批」，自动筛到那个套图（按所在文件夹名）并按「最近更新提示词」排序
8. **关联生成图**：打开一张图的详情 →「生成图」区块的「＋ 关联生成图」→ 在图库里勾选用它的提示词生成的图 →「确定」。见下面「图片关联」

## 功能

| 功能 | 怎么用 |
| --- | --- |
| 筛选 | 左栏：文件夹树（点文件夹看它和所有子文件夹里的图，点 ▸ ▾ 展开收起，展开状态浏览器会记住；「（根目录）」是直接放在根下的图；「全部图片」是所有图）、图库目录外（在「反推设置」→「反推目录」里反推的）、仅导入记录（还没对上真实图片的）、空白套图（组合器里从 0 建的，下面列出各套图）；状态：未反推 / 有提示词 / 文件已不在 |
| 搜词 | 工具栏搜索框：含某个词的图，先规范化（大小写、下划线），支持别名和部分匹配 |
| 排序 | 最近更新提示词（默认）/ 最近入库 / 按文件夹、文件名 |
| 网格 | 工具栏「网格」只看缩略图，适合挑图 |
| 黑名单词 | 默认不显示；勾「显示黑名单词」以删除线显示 |
| 显示段 | 列表上方勾选要看的段，没勾的段在所有卡片里隐藏。只勾「姿势」时每张图只剩一行，适合做套图时对比所有图的姿势。和紧凑、置信度数字一样只影响显示，浏览器会记住 |
| 图片详情 | 点缩略图或「详情」：大图、路径、尺寸、反推模型和参数、所在的预设组（命中 ≥ 50% 的，显示命中数）、关联的生成图 / 原图、按段的词（可改）、完整提示词。← → 翻上一张 / 下一张（在当前筛选里），Esc 关闭 |
| 词典联动 | 词典页词详情里的「出现在这些图里」是缩略图，点一张直接在图库打开 |

## 图片关联

记录「哪张图是用哪张图的提示词生成的」。每张图的详情里都有两个区块：

- **生成图**：用这张图的提示词生成的图
- **原图**：这张图是用哪些图的提示词生成的

一对图只关联一次，两边同时显示：在 A 的「生成图」里加了 B，B 的「原图」里自动就有 A。支持多对多：一张原图可以有多张生成图，一张生成图也可以有多张原图。

- **关联**：区块标题旁的「＋ 关联生成图 / ＋ 关联原图」进入挑图模式。图库页顶部出现提示条，左栏、搜词、筛选、翻页照常用，勾选要关联的图后点「确定」，回到原来那张图的详情。已经关联过的图标「已关联」、不能再勾。「取消」或 Esc 不改任何东西直接回去。挑图结束后恢复进入前的筛选；下次挑图从上次挑图的位置开始
- **查看**：点关联的缩略图打开那张图，抽屉顶部有「← 返回『…』」回到之前那张
- **取消关联**：鼠标移到缩略图上点右上角的 ×，两边一起消失
- 关联和取消关联都可以撤销（Ctrl+Z）
- 不能反向重复：已经有 A → B（B 是 A 的生成图），就不能再建 B → A，会提示「方向相反」。要改方向先取消原来的关联
- 图被挪到别的文件夹后再扫描，关联保留

## 预设组

左栏「预设组」列出所有预设组（预设组怎么建、怎么编辑见 `组合器-使用说明.md`）。主题已经换成预设组，原来的主题界面去掉了（数据还在库里）。

- **哪些图算这个组的**：图上有组里的词（各段预设的词，不含 LoRA；大小写、下划线、别名都认，黑名单词也算）达到一定比例就算，默认 50%。比如组里 22 个词，图上有 11 个以上就算。组改了词、图改了词，结果马上跟着变
- **查看**：左栏点一个组，只看这个组的图。和目录筛选二选一（点组会取消文件夹筛选，点文件夹会取消组）；「状态」和搜词照样可以一起用。工具栏的「× 预设组」取消
- 选了组时：
  - 提示行里的滑块调阈值（5% 一档，记在浏览器里），左栏各组的图数跟着变
  - 排序自动换成「命中比例」（命中多的在前），离开组后换回原来的排序
  - 每张图上显示「命中 13/22」
  - 「编辑这个组」打开预设组编辑器，候选来源默认是这个组的图
- **图片详情**的「所在的预设组」：列出这张图命中 ≥ 50% 的组（固定 50%，不跟滑块走）和命中数；点名字在图库里看这个组，「编辑」打开编辑器
- 左栏「＋ 新建预设组」：打开编辑器，候选是当前筛选的高频词
- 以上操作都可以撤销（Ctrl+Z）
- 平时所有图都能勾选（仅导入记录也行）；「反推选中的图」会自动跳过仅导入记录和文件已不在的图

## 词频与存预设

工具栏的「词频」：统计**当前筛选的全部图**（不只这一页）每段的词，按出现的张数从多到少排，显示「张数 · 占比」。当前筛选可以是一个预设组、一个文件夹，再加上状态和搜词。

- 「最低占比」滑块（默认 30%）：低于它的词先收起，点「还有 N 个低于 …% 的词」展开
- 黑名单词默认不显示，勾「显示黑名单词」后以删除线显示
- **存预设**：在一段里勾选词 → 段标题旁的「存为预设」→ 填名称（默认「预设组或目录名·段名」）→ 保存。预设属于这一段，内容是勾选的词，按占比从高到低排。同一段里重名时会问要不要覆盖。可以撤销
- **预设组**：跨段勾选（比如角色段勾触发词、外貌段勾发色和瞳色）→ 顶部「预设组…（已勾 N）」打开预设组编辑器（和组合器里的是同一个，用法见 `组合器-使用说明.md`）。勾选的词按段放进左边，标「新加」，不要的点 ×；右边候选默认就是这次的词频，可以接着点词加。不勾也能直接打开挑词
- 编辑器左上角选「新建」（名字默认预设组或目录名）还是「加到「某个组」」：加到已有组时组里原来的词照常在，这次带来的词接在后面标「新加」，已经有的不重复加。新建时名字和已有的组撞了，会提示「改成加到它里面」
- 工具栏的「预设组…」：候选是当前筛选全部图的词频，不用先开词频
- 图片详情底部的「预设组…」：候选是这张图的词，点词加入
- 保存整组一次撤销
- 预设在组合器左栏管理，见 `组合器-使用说明.md`

## 手工改过的图

在图上增删词、调词序之后，这张图标「手工改过」。之后：

- 反推（「反推设置」→「反推目录」或图库里发起的）和导入 txt / xlsx **默认跳过**手工改过的图，报告里列出跳过了哪些
- 勾「也覆盖手工改过的图」才会整图重写，报告里列出覆盖了哪些

词的归类（词典级）不受这个影响。

## 只扫一个子目录

扫描页的「只扫这个子目录」：填相对图库根的路径（如 `参考图/角色A`）或完整路径，留空扫整个图库。图库页筛到某个文件夹时，提示行里的「只扫描这个目录」会自动填好。

- 文件夹路径仍按图库根算，所以**图库根目录不要改成子目录**，不然左栏的路径会变
- 「文件已不在」只在这个子目录里判断；从别处挪进这个子目录的图照样认成移动
- 没变过的图本来就很快（实测每张约 0.02 ms，1 万张约 0.2 秒），只扫子目录主要省在机械硬盘列目录上

## 扫描报告里的几种情况

| 情况 | 处理 |
| --- | --- |
| 回填导入记录 | txt / xlsx 导入的占位记录对上了真实图片，标签保留 |
| 移动 | 同内容的文件换了路径（原路径已不在），记录跟过去，标签和关联保留 |
| 内容变了 | 同路径文件内容变了，重生缩略图，标签不动；要不要重新反推你决定 |
| 同内容重复文件 | 只登记第一个，其余列出来 |
| 同名导入记录不止一条 | 不猜，新建记录，列出候选 |
| 文件已不在 | 完整扫完时才判定，只判图库根下的；记录和标签保留，可以在「文件已不在」里筛出来 |

## 配置（`config.json`）

| 键 | 说明 |
| --- | --- |
| `gallery_root` | 默认图库根目录，默认留空，要自己填；也可以在扫描页填 |
| `thumbs_dir` | 缩略图目录，默认 `data/thumbs`。长边 256 的 webp，文件名是图片 id；删掉会在扫描或打开时补 |

## 已知限制

- 只读图片：不移动、不改名、不删除，也不提供删除记录
- 同一张图在两个不同目录名下分别导入 / 反推过，会是两条记录（例如 `test/` 的导入记录和 `batch_in/` 的反推记录），目前不能合并
- 二期 A 之前在「反推目录」里反推的图没有 sha1，和图库里的同一张图认不出是重复；重新反推一次就有了
- 大目录首次扫描主要耗时在算 sha1 和生成缩略图
