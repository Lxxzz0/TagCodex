# 标签词典 · 使用说明

## 启动

首次使用先双击 `install.bat`（要先装 Python 3.10 以上）：建 `.venv`、装依赖、生成 `config.json`、下载 danbooru 表，并询问要不要启用内置反推（要下载约 1.3GB 的模型）。可以重复运行，做过的步骤会跳过；以后想启用反推再运行一次就行。模型先从 huggingface.co 下，连不上自动换国内镜像 hf-mirror.com（想直接指定就先设环境变量 `HF_ENDPOINT`）；下到一半断了，再运行会接着下。

之后双击 `run.bat`，自动打开 http://127.0.0.1:5077/ 。第一次进去先在顶栏「反推设置」→「danbooru 参考表」里导入 danbooru 表。

Vue 从 CDN 加载，首次打开会白屏 3–5 秒。需要联网。

## 日常流程

1. **反推入库**：
   - 顶栏「反推设置」→「反推目录」，直接在管理器里反推，不用开 ComfyUI。eva02 约 1 秒一张，图多就分批跑；图放进图库的话也可以在图库里扫描后反推
   - 已经按段分好的 xlsx / txt（格式见导入对话框，组合器导出的就是）用「导入 xlsx / txt 目录」。机器反推的原始文件，「以文件分节为准」保持关闭
2. **清未归类队列**：打开默认就是「未归类，按出现次数倒序」。点选词（Shift 连选）→ 按数字键 1–9 归到对应段
3. **处理分歧**：顶部「有分歧」或左侧筛选。鼠标悬停在「文件分歧 / 机器分歧」标记上看各方意见
4. 词典每次改动 1.5 秒后自动重写 `tag_dict.json`（见下面「tag_dict.json」），读它的程序下次运行就能用上

## 十段

段的顺序就是拼接顺序。归不准时按「看到这个词，它说的是什么」判断：

| 段 | 放什么 |
| --- | --- |
| 角色 | 画的是谁：人数（`1girl`）、角色名、作品名、身份（`maid`）、触发词 |
| 外貌 | 长在身上的：发型发色、瞳色、体型、身体部位、兽耳、尾巴、痣 |
| 服饰 | 穿戴的：衣服、鞋袜、饰品、眼镜 |
| 表情 | 脸上的状态和情绪：`smile`、`blush`、`tears`、`open mouth` |
| 姿势 | 动作、手持（`holding x`）、视线（`looking at viewer`）、互动 |
| 镜头 | 机位、景别、构图、景深 |
| 环境 | 地点、物件、背景、天气、时间（`night`） |
| 氛围 | 光和色调：`backlighting`、`rim light`、`dark` |
| 画风 | 画师名，以及介质、技法、线条、整体色彩风格 |
| 未归类 | 包括 `highres` 这类质量词，自己拉黑或归段 |

机器归类按 danbooru 的大类/小类直接对应到段（对照表在 `importer.py` 的 `_DANBOORU_GROUPS`）。一个小类里混着不同性质的词时只能按多数归，比如 `solo` 会进镜头、`blush` 会进外貌，手动改一次之后不会再被覆盖。画师名没有机器来源，用「粘贴添加」归到画风。

## 功能

| 功能 | 怎么用 |
| --- | --- |
| 批量归位 | 选词 → 操作栏点段名，或按 1–9 |
| 拉黑 | 选词 → 「拉黑」或按 B；黑名单词不进复制的提示词和组合器输出，`tag_dict.json` 里列在 `blocked` |
| 加入预设组 | 选词 → 「加入预设组…」，打开预设组编辑器（见 `组合器-使用说明.md`），选中的词按各自所在的段放进去、标「新加」。左上角选「新建」或「加到「某个组」」。词详情里「所在的预设组」列出包含这个词的组，点名字打开编辑器 |
| 合并同义词 | 只用于同一个词的不同写法（如 `long hair` / `long_hair`）。选 2 个以上 → 「合并同义词」，选主词；其余词从词典删掉变成别名，图上的这些词换成主词，出现次数合并，`tag_dict.json` 里记成别名。**不要**用它把不同的词打包（比如角色触发词 + 外貌词），打包用预设组，见 `组合器-使用说明.md` |
| 撤销 | 操作后的提示里点「撤销」、顶部「撤销」或 Ctrl+Z。▾ 看最近 10 次。只能从最新的往回撤 |
| 反推目录 | 顶栏「反推设置」→「反推目录」：选目录、模型、阈值，开始后可关掉对话框，顶部显示进度；可停止；默认跳过已反推过的图。置信度会存下来 |
| 粘贴添加 | 「添加 / 导入」→「粘贴添加」。批量录入角色名、画师名，自动补中文 |
| 粘贴拆分 | 工具栏「粘贴拆分…」：粘一整段提示词，按词典拆到各段。已归好段的词只是列出来、不改；词典里没有的、未归类的、有分歧的列在「要定段的词」，每个选一个段（默认「不要」），「加进词典」后新词建到选的段、已有的改到选的段（算手工归类）。一次确定一次撤销。`<lora:…>` 跳过 |
| 用调好的表定分类 | 在 Excel 里把 xlsx 调整好 → 导入时勾「以文件分节为准」。文件里的分节直接成为词库归属，可撤销 |
| 词详情 | 每行右边「详情」：反查出现在哪些图、改中文和备注、移除别名、看各方意见 |
| 段管理 | 左侧「段」旁的「管理」：拖动排序、点名字改名、「拼」开关、× 删除（未归类不能删）、新增段 |
| 完整导出 | 顶部「导出 ▾」→ CSV（Excel 直接打开）或 JSON。做版本备份用 |
| 主题 | 顶部右侧，跟随系统 / 浅色 / 深色 |

快捷键在输入框里、或对话框打开时不生效。Esc 清空选择 / 关闭详情。

## 配置（`config.json`）

| 键 | 说明 |
| --- | --- |
| `host` / `port` | 默认 127.0.0.1:5077 |
| `db_path` | 词库，默认 `data/tagcodex.db`。备份就复制这一个文件 |
| `tag_dict_path` | 词典快照，默认 `data/tag_dict.json`，见下面「tag_dict.json」 |
| `danbooru_xlsx` | danbooru 参考表，只读，默认 `data/danbooru_tags.xlsx`（install.bat 下载）。大类/小类到段的映射写在 `importer.py` 里 |
| `tagger` | 内置反推：`models_dir` 模型目录（只读，默认 `data/models`，install.bat 下载；也可以指向 comfyui-wd14-tagger 的 models 目录）、默认 `model` / `threshold` / `character_threshold` / `exclude_tags` |
| `gallery_root` / `thumbs_dir` | 图库根目录和缩略图目录，见 `docs/图库-使用说明.md` |
| `composer_output_dir` | 组合器默认输出目录，留空则导出时自己填 |

`config.json` 第一次启动时从 `config.example.json` 生成。相对路径都相对项目目录。路径留空或文件不存在时，只有对应功能不能用，界面上会提示。

## tag_dict.json

词库本身在 `db_path`（默认 `data/tagcodex.db`），`tag_dict.json` 是从它自动导出的快照：词典每次改动后约 1.5 秒重写一次（先写临时文件再替换，读的一方不会读到写一半的文件）。给 ComfyUI 节点之类的外部程序读，用来按你定的段给标签分段。格式：

```json
{
  "version": 2,
  "generated": "2026-10-12T12:00:00",
  "buckets": [{"key": "character", "name": "人物", "joins": true}, "..."],
  "tags": {"1girl": "character", "school uniform": "outfit"},
  "aliases": {"schoolgirl uniform": "school uniform"},
  "blocked": ["watermark"]
}
```

- `buckets`：段，按排序；`joins` 是这段拼提示词时要不要拼
- `tags`：词 → 段 key。词都是规范化后的写法（小写、下划线换空格）
- `aliases`：别名 → 主词，查段时先换成主词
- `blocked`：黑名单，分段时应该丢掉
- 规则表兜底落到「未归类」的词不写进 `tags`，读的一方自己处理

## 已知限制

- 改段名、排序、改中文备注不进撤销（直接改回去即可）
- 已经导出的 txt / xlsx 不会随词典改动重写，要重新导出用组合器
- 「反推目录」只读一层目录；按角色/套图递归登记用「扫描图库」，再在图库里反推
- 内置反推只用 CPU；同一时间只能跑一个反推任务
- 规则表（项目里的 `tag_rules.py`，可以直接改）只认旧六段，它的意见里「人物」按角色处理；它说人物而 danbooru 说外貌/表情、说姿势而 danbooru 说表情、说环境而 danbooru 说氛围，不算机器分歧
