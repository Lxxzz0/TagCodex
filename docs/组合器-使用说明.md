# 组合器 · 使用说明

拿一批图的提示词，按段批量换掉角色、服饰、画风等，预览后导出 txt 目录 / xlsx，拿去批量出图。

顶栏切到「组合器」。页面分三块：左边是预设库，中间是槽（每段一个），右边是预览。

## 1. 预设组（左栏）

预设组 = 一个名字下的一组提示词，按段分开存。比如「角色A」：角色段放触发词（加 LoRA），外貌段放发色、瞳色，服饰段放默认衣服。只有一段的也算一个预设组。

- 左栏每个预设组一张卡片，按段列出词和 LoRA。☆ 加星标（排在前面），搜索框搜名称、内容和 LoRA
- **套用**：卡片上的「套用」，或者**把整张卡片拖到中间任意一个槽上**（拖动时组里各段的槽一起高亮），组里每段按「替换」放进对应的槽。槽上方的「整组套用…」也一样
- **新建 / 编辑**：「＋ 新建预设组」或卡片上的「编辑」打开编辑器：
  - 左边「组里的词」：每段的已选词，点 × 去掉，拖动调整顺序；每段一个 LoRA 框（写 `名字:权重` 或 `<lora:名字:权重>`，多个用逗号分隔，输出时放在这段最前面）；「清空」整段
  - 右边「挑词」：先选候选来源（组合器当前来源 / 词典按出现次数 / 某个预设组命中的图 / 某个套图），再点段的标签切换段，点词加入，已选的词再点一下去掉。点左边的某一段也会切到那一段
  - 搜索框：英文、中文都能搜；回车把输入的词直接加进当前段（词典里没有的也行，逗号分隔可一次加多个）
  - 段不用先加：有词或 LoRA 的段就进组，清空的段保存时从组里去掉
  - 顶部名字框改名就是整组改名（新名字已经被别的预设组用了会报错）
  - 「删除这个预设组」删掉整组
  - 保存、删除、星标都是整组一次操作，撤销一次整组还原（Ctrl+Z）
- 从别的页面打开同一个编辑器：图库工具栏 / 词频抽屉 / 图片详情的「预设组…」，词典多选后的「加入预设组…」，词典词详情里「所在的预设组」点名字。从这些入口打开时左上角可以选「新建」还是「加到「某个组」」，带来的词标「新加」；右边多一个这个入口自己的候选来源（这次的词频、这张图的词），见 `图库-使用说明.md`、`标签词典-使用说明.md`

## 2. 选来源

来源决定输出几条：每张来源图一条，一批最多 1000 张。

- **从图库送过来**：图库工具栏的「送到组合器」。有勾选的图就送勾选的，没有就送当前筛选的全部图（套图、预设组、搜词都行），顺序是图库当前的排序
- **在组合器里选**：工具栏「选来源…」，列出空白套图、全部预设组（命中的图，阈值用图库里设的）和文件夹（直接放了图的，不含子文件夹）
- 没有提示词的图会跳过，预览上方会写跳过了几张（空白套图的空白条不跳过）。黑名单词不会带进来
- **从 0 建一个套图**：见下面「空白套图」

来源和槽的设置浏览器会记住，下次打开还在。

### 空白套图

不拿已有的图当来源，直接建若干条空白提示词，一条对应一张要出的图。

- **新建**：工具栏「＋ 新建套图」，填套图名（不能和已有的套图重名，默认「套图-日期」）和条数（1–200），建好后自动设成来源
- 来源是空白套图时，来源下面多一行：
  - 「＋1 条」「加 N 条」：接着现有最大序号往后加
  - 「写入」：把预览里的结果整份写进条里（槽有改动时才能点）。**先勾选几条，就只写这几条**（按钮变成「写入选中的 N 条」，没勾的条变淡、不动）；没勾选时是「写入全部」。预览上方有「全选本页」。写完可以「全部重置」槽，换一组槽再组合再写；不重置也行，预览和写进去的一样。词典里没有的词放进你填它的那一段。LoRA 不写进条里（它跟着预设走），导出时在槽里放上带 LoRA 的预设
  - 每条的「编辑」：打开详情，和图库一样按段加词、删词、拖动调序
  - 勾选若干条 →「删掉选中的条」；「清空选择」
  - 「改名」「删除套图」
- 导出的文件名是「套图名_001.txt」这样，还没填词的条也导出（空 txt）
- 新建、加条、删条、写入、改名、删除和逐条改词都可以撤销
- 图库左栏也能看到空白套图（见 `图库-使用说明.md`），在那里点「送到组合器」会回到这个套图的操作

## 3. 槽

每段一个槽，顺序跟词典一致。每个槽选一种方式：

| 方式 | 结果 |
| --- | --- |
| 保留 | 用原图这段的词（默认） |
| 替换 | 这段换成填的内容；什么都没填时这段会被清空 |
| 前加 / 后加 | 原来的词保留，在前面 / 后面加上填的内容 |
| 删词 | 去掉填的这些词（大小写、下划线、别名都认） |
| 清空 | 这段为空 |

- **填内容**：选「替换 / 前加 / 后加 / 删词」后，槽里可以「＋ 预设…」选这一段的预设（可以选多个），也可以手写（逗号分隔，排在预设后面）。手写框旁的「挑词…」打开挑词框，从词典里挑这一段（也可以换段）的词，确定后接在手写框后面，已经写过的词不能再选；「删词」方式下挑的就是要删的词
- **槽里微调**：槽里选了预设时，下面列出预设里的词。点一个词只在**这个槽里**去掉（划掉显示），再点一下恢复，预设本身不变。槽有改动（去掉了词，或手写了词）时出现「存回预设」：去掉的词从各自的预设里删掉，手写的词加到槽里第一个预设的末尾，然后清空划掉标记和手写框，预览结果不变。每个被改的预设各算一次操作，改了几个就要撤销几次
- **整组套用**：槽上方的「整组套用…」选一个预设组，组里每个预设按「替换」填进它那一段。换角色时一次换掉角色、外貌、服饰
- **全部重置**：所有槽回到「保留」
- 一条提示词里同一个词只留第一次出现的位置（比如角色段已经有 `1girl`，环境段再加 `1girl` 会被去掉）

## 4. 预览

改了槽之后会自动重新算。每张来源图一行：

- 只显示有词的段；改过的段名是蓝色
- 新加的词是绿框，删掉的词是红色删除线
- 最下面一行是完整提示词：按段顺序拼，跳过不参与拼接的段

## 5. 导出

预览上方的「导出…」：

- **输出根目录**：默认是 `config.json` 的 `composer_output_dir`，改过会记住。不能选在图库目录里面
- **批次名**：默认「来源名-日期」。导出到 `输出根目录/批次名/`
- **txt 目录**：每张来源图一个 `文件名.txt`，每段一节（一行 `[段名]`，下一行是这段的词，空段也写节名）。同一批里文件名重复时，从第二个起加 `_2`、`_3`
- **xlsx**：`批次名.xlsx`，列是 序号 / 图 / 文件名 / 每段一列 / 完整提示词，带缩略图
- 同目录还会写 `_组合记录.json`：来源图（id、路径、对应的 txt）和每个槽的设置（含槽里去掉的词 `exclude`）
- 目录里已经有同名文件时会列出来，点「覆盖并导出」才写；目录里其他文件不动

导出只写文件，不改数据库，不进撤销。

## 6. 拿去出图

导出的 txt 是纯文本，可以给 ComfyUI 等工具按目录批量读取；不需要分段的话，直接用 xlsx 里的「完整提示词」列。画风段默认排在第 9 位，所以拼出来画风词在后面；想放最前，在词典里把画风段拖到第一。

## 7. 导回

导出的 txt / xlsx 可以用「添加 / 导入」导回管理器。`<lora:...>` 标记会跳过、不建成词，报告里写「跳过 LoRA 标记 N 个」。

## 已知限制

- 槽设置不能存成命名的「配方」，只记最近一次的（浏览器里）；需要追查时看 `_组合记录.json`
- 导出后不会自动关联生成图和原图，出完图在图库里手动关联
- 每张来源图固定对应一条输出，不做随机组合
