# 组合器 · 使用说明

两种用法，按有没有选来源自动切换：

- **单条编辑**（没有来源）：从词典挑词、套预设、粘贴，按段组合出一条提示词，复制走或存成预设组
- **批量替换**（选了来源）：拿一批图的提示词，按段换掉角色、服饰、画风等，预览后导出 txt 目录 / xlsx，拿去批量出图

顶栏切到「组合器」。页面分三块：左边是预设组，中间是提示词文本框和「按段编辑…」，右边是结果（单条）或预览（批量）。

## 1. 预设组（左栏）

预设组 = 一个名字下的一组提示词，按段分开存。比如「角色A」：角色段放触发词，外貌段放发色、瞳色，服饰段放默认衣服。只有一段的也算一个预设组。

- 左栏每个预设组一张卡片，按段列出词和 LoRA。☆ 加星标（排在前面），搜索框搜名称、内容和 LoRA
- **复制**：鼠标移到某一段那行，右边出现「复制」，复制这段的词；卡片头上的「复制整组」按段顺序复制整组的词（跳过不参与拼接的段，跨段重复的只留一个）。都**不带 LoRA**，写法原样，`, ` 连接
- **套用**：卡片上的「套用」，或者**把整张卡片拖到中间的编辑区**，组里每段的词**覆盖**进对应的段，组里没有的段不动。按段编辑弹窗顶部的「应用预设组…」也一样。只取词，不带 LoRA
- **新建 / 编辑**：「＋ 新建预设组」或卡片上的「编辑」打开编辑器：
  - 左边「组里的词」：每段的已选词，点 × 去掉，拖动调整顺序；每段一个 LoRA 框（写 `名字:权重` 或 `<lora:名字:权重>`，多个用逗号分隔；组合器不再用 LoRA，这里只是存着）；「清空」整段
  - 右边「挑词」：先选候选来源（组合器当前来源 / 词典按出现次数 / 某个预设组命中的图 / 某个套图），再点段的标签切换段，点词加入，已选的词再点一下去掉。点左边的某一段也会切到那一段
  - 搜索框：英文、中文都能搜；回车把输入的词直接加进当前段（词典里没有的也行，逗号分隔可一次加多个）
  - 搜索框旁的「粘贴…」：粘一整段提示词，按词典拆到各段，当作「新加」的词放进组里（见下面「粘贴拆分」）
  - 段不用先加：有词或 LoRA 的段就进组，清空的段保存时从组里去掉
  - 顶部名字框改名就是整组改名（新名字已经被别的预设组用了会报错）
  - 「删除这个预设组」删掉整组
  - 保存、删除、星标都是整组一次操作，撤销一次整组还原（Ctrl+Z）
- 从别的页面打开同一个编辑器：图库工具栏 / 词频抽屉 / 图片详情的「预设组…」，词典多选后的「加入预设组…」，词典词详情里「所在的预设组」点名字。从这些入口打开时左上角可以选「新建」还是「加到「某个组」」，带来的词标「新加」；右边多一个这个入口自己的候选来源（这次的词频、这张图的词），见 `图库-使用说明.md`、`标签词典-使用说明.md`

## 2. 选来源

没有来源时是单条编辑；选了来源就是批量替换，来源决定输出几条：每张来源图一条，一批最多 1000 张。

- **从图库送过来**：图库工具栏的「送到组合器」。有勾选的图就送勾选的，没有就送当前筛选的全部图（套图、预设组、搜词都行），顺序是图库当前的排序
- **在组合器里选**：工具栏「选来源…」，列出空白套图、全部预设组（命中的图，阈值用图库里设的）和文件夹（直接放了图的，不含子文件夹）；选「无（单条编辑）」回到单条编辑
- 没有提示词的图会跳过，预览上方会写跳过了几张（空白套图的空白条不跳过）。黑名单词不会带进来
- **从 0 建一个套图**：见下面「空白套图」

来源和各段的设置浏览器会记住，下次打开还在。

### 空白套图

不拿已有的图当来源，直接建若干条空白提示词，一条对应一张要出的图。

- **新建**：工具栏「＋ 新建套图」，填套图名（不能和已有的套图重名，默认「套图-日期」）和条数（1–200），建好后自动设成来源
- 来源是空白套图时，来源下面多一行：
  - 「＋1 条」「加 N 条」：接着现有最大序号往后加
  - 「写入」：把预览里的结果整份写进条里（中间有改动时才能点）。**先勾选几条，就只写这几条**（按钮变成「写入选中的 N 条」，没勾的条变淡、不动）；没勾选时是「写入全部」。预览上方有「全选本页」。写完可以「清空」中间的内容，换一组再组合再写；不清空也行，预览和写进去的一样。词典里没有的词放进你填它的那一段
  - 每条的「编辑」：打开详情，和图库一样按段加词、删词、拖动调序
  - 勾选若干条 →「删掉选中的条」；「清空选择」
  - 「改名」「删除套图」
- 导出的文件名是「套图名_001.txt」这样，还没填词的条也导出（空 txt）
- 新建、加条、删条、写入、改名、删除和逐条改词都可以撤销
- 图库左栏也能看到空白套图（见 `图库-使用说明.md`），在那里点「送到组合器」会回到这个套图的操作

## 3. 提示词和按段编辑

### 文本框

中间的文本框就是各段内容的另一种显示：

- **粘贴或修改后离开文本框**，按词典拆到各段（写法保持原样，别名认到主词那段，同一个词只留一次），然后文本框换成按段顺序重排后的样子
- 词典里有的词都放进它现在的段，和图库里显示的一样：有分歧的按现在的段，未归类的进「未归类」段
- 词典里没有的词不进任何段，文本框下面提示「⚠ N 个词词典里没有」，点它打开按段编辑给它们选段，可以同时加进词典
- 方式是「删词」「清空」的段不跟文本框走；拆到这些段的词也要在按段编辑里重新选段
- `<lora:…>` 跳过
- 「清空」：所有段清空（批量替换时 = 全部保留原图）
- 批量替换时，文本框下面列出改了哪些段、怎么改的，点一段打开按段编辑并定位到那段

### 按段编辑

「按段编辑…」打开弹窗，每段一个框（逗号或换行分隔），两列排开。改完点「确定」才生效，「取消」或 Esc 丢掉这次的改动。

- 顶部「应用预设组…」：组里每段的词覆盖进对应的框
- 每个框上方：
  - 「预设…」：这一段的预设，选了覆盖这一段
  - 「挑词…」：从词典挑这一段（也可以换段）的词，接在框里后面，已经有的词不能再选
  - 「复制」：复制这个框里的词
- 框里有词典里属于别的段的词时，下面小字提示「词典里：xx 属于「外貌」」，不会自动挪
- 框里有词典里没有的词时，下面提示「词典里没有：xx」，点「加进词典（这一段）」新建到词典的这一段（可以撤销）
- 「要选段的词」：每个选一个段，「确定」时接到那段后面；「不要」的丢掉。勾着「同时加进词典」（默认勾）时，词典里没有的词按选的段加进词典，算一次操作
- 「存为预设组…」：用框里现在的词打开预设组编辑器（不用先确定）
- 「全部清空」：所有框清空

**批量替换时**每个框右上角多一个方式：

| 方式 | 结果 |
| --- | --- |
| 自动（默认） | 框空着：保留原图这段；有词：这段换成框里的词 |
| 前加 / 后加 | 原来的词保留，在前面 / 后面加上框里的词 |
| 删词 | 去掉框里的这些词（大小写、下划线、别名都认） |
| 清空 | 这段为空 |

一条提示词里同一个词只留第一次出现的位置（比如角色段已经有 `1girl`，环境段再加 `1girl` 会被去掉）。

### 单条编辑的结果

没有来源时右边是「结果」：按段列出这一条的词（点段名复制这一段），下面是完整提示词（跳过不参与拼接的段）。

- 「复制提示词」：复制完整提示词
- 「存为预设组…」：各段的词带进预设组编辑器，可以新建或加到已有组

### 粘贴拆分

预设组编辑器的「粘贴…」、词典页的「粘贴拆分…」是同一个对话框：粘一段提示词（逗号、换行分隔），点「拆分」。

- 按词典把每个词放进它所在的段，写法保持原样；别名认到主词那段，同一个词只留一次
- 黑名单词照常放进它的段，标「黑名单」，不想要可以放进去后再删
- 有分歧的词按现在的段放，标「有分歧」；未归类的进「未归类」段
- 「词典里没有的词」：每个词选一个段，默认「不要」（不帮你决定归类）；勾着「同时加进词典」（默认勾）时，选了段的顺手加进词典
- `<lora:…>` 跳过，写跳过了几个
- 放进预设组编辑器：各段的词接在已选词后面、标「新加」，保存前都能去掉
- 词典页的「粘贴拆分…」除了词典里没有的，未归类、有分歧的词也列出来让你定段（见 `标签词典-使用说明.md`）

## 4. 预览

批量替换时，中间改了之后会自动重新算。每张来源图一行：

- 只显示有词的段；改过的段名是蓝色
- 新加的词是绿框，删掉的词是红色删除线
- 最下面一行是完整提示词：按段顺序拼，跳过不参与拼接的段
- **复制**：点段名复制这条这一段的词（删掉的不复制）；完整提示词后面的「复制提示词」复制整条

## 5. 导出

预览上方的「导出…」：

- **输出根目录**：默认是 `config.json` 的 `composer_output_dir`，改过会记住。不能选在图库目录里面
- **批次名**：默认「来源名-日期」。导出到 `输出根目录/批次名/`
- **txt 目录**：每张来源图一个 `文件名.txt`，每段一节（一行 `[段名]`，下一行是这段的词，空段也写节名）。同一批里文件名重复时，从第二个起加 `_2`、`_3`
- **xlsx**：`批次名.xlsx`，列是 序号 / 图 / 文件名 / 每段一列 / 完整提示词，带缩略图
- 同目录还会写 `_组合记录.json`：来源图（id、路径、对应的 txt）和改了的各段设置（方式、填的词）
- 目录里已经有同名文件时会列出来，点「覆盖并导出」才写；目录里其他文件不动

导出只写文件，不改数据库，不进撤销。

## 6. 拿去出图

导出的 txt 是纯文本，可以给 ComfyUI 等工具按目录批量读取；不需要分段的话，直接用 xlsx 里的「完整提示词」列。画风段默认排在第 9 位，所以拼出来画风词在后面；想放最前，在词典里把画风段拖到第一。

## 7. 导回

导出的 txt / xlsx 可以用「添加 / 导入」导回管理器。`<lora:...>` 标记（旧版导出的、或者手写进去的）会跳过、不建成词，报告里写「跳过 LoRA 标记 N 个」。

## 已知限制

- 各段的设置不能存成命名的「配方」，只记最近一次的（浏览器里）；想留下来用「存为预设组…」，需要追查时看 `_组合记录.json`
- 导出后不会自动关联生成图和原图，出完图在图库里手动关联
- 每张来源图固定对应一条输出，不做随机组合（以后做「抽词组合」）
